# CSMA File Repository

## Repositorio de Archivos para Música y Baile

Este repositorio proporciona una estructura completa y organizada para almacenar todo tipo de documentos y archivos relacionados con la industria de la música y el baile.

## 📁 Estructura del Repositorio

### 🎵 Música (`/musica`)
Almacena todo el contenido relacionado con música:
- **generos/**: Archivos organizados por género musical (rock, jazz, clásica, pop, electrónica, folk, reggaeton, salsa, bachata, merengue)
- **composiciones/**: Obras musicales y composiciones originales
- **grabaciones/**: Grabaciones de audio y sesiones de estudio
- **partituras/**: Partituras y notaciones musicales
- **letras/**: Letras de canciones y textos musicales

### 💃 Baile (`/baile`)
Contenido relacionado con danza y baile:
- **estilos/**: Organizados por estilo de baile (ballet, contemporáneo, hip-hop, salsa, bachata, tango, flamenco, jazz, breakdance, folklórico)
- **coreografias/**: Diseños y documentación de coreografías
- **presentaciones/**: Material de presentaciones y shows
- **ensayos/**: Videos y notas de ensayos

### 📚 Educación (`/educacion`)
Materiales educativos y de formación:
- **cursos/**: Contenido de cursos completos
- **talleres/**: Material de talleres y seminarios
- **tutoriales/**: Guías paso a paso y tutoriales
- **materiales-didacticos/**: Recursos educativos
- **examenes/**: Evaluaciones y exámenes
- **certificados/**: Certificados y diplomas

### 🎭 Eventos (`/eventos`)
Gestión de eventos y presentaciones:
- **conciertos/**: Documentación de conciertos
- **recitales/**: Material de recitales
- **festivales/**: Información de festivales
- **competencias/**: Competencias y concursos
- **presentaciones/**: Presentaciones generales
- **audiciones/**: Material de audiciones

### 🎬 Multimedia (`/multimedia`)
Archivos multimedia de diversos formatos:
- **audio/**: Archivos de audio
- **video/**: Videos y grabaciones
- **imagenes/**: Imágenes y gráficos
- **fotografias/**: Fotografías de eventos y artistas
- **grabaciones-en-vivo/**: Grabaciones de presentaciones en vivo

## 🚀 Uso del Repositorio

### Convenciones de Nomenclatura
- Usa nombres descriptivos para los archivos
- Incluye fechas en formato YYYY-MM-DD cuando sea relevante
- Usa guiones (-) en lugar de espacios en los nombres de archivo
- Ejemplo: `2025-11-04-concierto-salsa-festival.pdf`

### Organización de Archivos
1. Coloca cada archivo en la carpeta más específica posible
2. Si un archivo pertenece a múltiples categorías, colócalo en la categoría principal y crea referencias en las demás
3. Mantén un índice actualizado en cada carpeta principal

### Seguridad y Permisos
- Archivos sensibles (contratos, datos personales) deben mantenerse en `/administracion` con acceso restringido
- Multimedia de alta calidad puede requerir almacenamiento externo con enlaces en este repositorio
- Respeta siempre los derechos de autor y licencias

## 📝 Contribución
Para contribuir al repositorio:
1. Sigue la estructura de carpetas existente
2. Documenta cualquier archivo importante con un README en su carpeta
3. Mantén la consistencia en la nomenclatura
4. Actualiza este README si agregas nuevas categorías principales
