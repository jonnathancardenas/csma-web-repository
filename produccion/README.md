# Producción

Esta carpeta contiene recursos y documentación de producción.

## Estructura

### 📂 estudios/
Información de estudios de grabación y ensayo.

### 📂 equipamiento/
Inventario y documentación técnica de equipos.

### 📂 tecnicos/
Información de técnicos, ingenieros y personal de producción.

### 📂 escenografia/
Diseños y planos de escenografía.

### 📂 vestuario/
Catálogo y diseños de vestuario.

### 📂 iluminacion/
Planes de iluminación, riders técnicos.

### 📂 sonido/
Configuraciones de sonido, riders de audio.

## Uso
- Documenta especificaciones técnicas detalladas
- Mantén inventarios actualizados de equipamiento
- Archiva riders técnicos de todos los eventos
- Guarda planos y diseños en formatos editables
- Documenta configuraciones exitosas para reutilizar
