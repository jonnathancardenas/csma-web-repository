# Multimedia

Esta carpeta contiene archivos multimedia de diversos formatos.

## Estructura

### 📂 audio/
Archivos de audio: MP3, WAV, FLAC, etc.

### 📂 video/
Videos y grabaciones: MP4, MOV, AVI, etc.

### 📂 imagenes/
Imágenes y gráficos: JPG, PNG, SVG, etc.

### 📂 fotografias/
Fotografías de alta calidad de eventos, artistas y actividades.

### 📂 grabaciones-en-vivo/
Grabaciones de presentaciones y eventos en vivo.

### 📂 streaming/
Contenido preparado para transmisión en línea y plataformas digitales.

## Uso
- Mantén archivos originales en alta calidad
- Crea versiones optimizadas para diferentes usos
- Documenta metadatos: fecha, lugar, participantes
- Respeta derechos de imagen y propiedad intelectual
- Considera almacenamiento externo para archivos grandes

## Recomendaciones de Formato
- **Audio**: WAV/FLAC para originales, MP3 para distribución
- **Video**: MP4 H.264 para compatibilidad general
- **Imágenes**: PNG para gráficos, JPG para fotografías
