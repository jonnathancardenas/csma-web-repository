# Educación

Esta carpeta contiene materiales educativos y de formación.

## Estructura

### 📂 cursos/
Contenido completo de cursos estructurados.

### 📂 talleres/
Material de talleres, seminarios y workshops.

### 📂 tutoriales/
Guías paso a paso, video tutoriales y material instructivo.

### 📂 materiales-didacticos/
Recursos educativos, ejercicios y material de apoyo.

### 📂 examenes/
Evaluaciones, tests y exámenes de conocimiento.

### 📂 certificados/
Certificados de finalización, diplomas y reconocimientos.

## Uso
- Organiza cursos por nivel y especialidad
- Mantén versiones actualizadas de materiales
- Documenta requisitos previos de cada curso
- Guarda evidencia de certificaciones otorgadas
