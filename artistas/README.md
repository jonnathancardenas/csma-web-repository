# Artistas

Esta carpeta contiene información de artistas y profesionales.

## Estructura

### 📂 musicos/
Perfiles y documentación de músicos.

### 📂 bailarines/
Perfiles y documentación de bailarines.

### 📂 coreografos/
Información de coreógrafos y directores de danza.

### 📂 compositores/
Datos y obras de compositores.

### 📂 instructores/
Perfiles de instructores y profesores.

### 📂 biografias/
Biografías detalladas de artistas destacados.

### 📂 portafolios/
Portafolios profesionales, demos y material de presentación.

## Uso
- Mantén información actualizada de cada artista
- Incluye datos de contacto y disponibilidad
- Documenta especialidades y repertorio
- Archiva material promocional y currículum
- Respeta la privacidad y protección de datos personales
