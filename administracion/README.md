# Administración

Esta carpeta contiene documentos administrativos y legales.

## Estructura

### 📂 contratos/
Contratos de servicios, trabajo y colaboración.

### 📂 licencias/
Licencias de uso, permisos y autorizaciones.

### 📂 derechos-autor/
Documentos de derechos de autor, registros y cesiones.

### 📂 facturas/
Facturas, recibos y documentación contable.

### 📂 presupuestos/
Presupuestos, cotizaciones y estimaciones de costos.

### 📂 documentos-legales/
Otros documentos legales y administrativos.

### 📂 seguros/
Pólizas de seguro y documentación relacionada.

## Uso
- **CONFIDENCIAL**: Acceso restringido a personal autorizado
- Mantén copias de seguridad cifradas
- Documenta fechas de vencimiento y renovaciones
- Archiva versiones firmadas de todos los contratos
- Cumple con regulaciones de protección de datos
- Consulta con asesoría legal antes de archivar o eliminar
